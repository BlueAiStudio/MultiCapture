# Themes / 主题

Every folder here is one theme. The app ships with these folders, and "Get online themes" in the app downloads
new or updated folders from here, so a theme added to this folder reaches users without a new release.

这里的每个文件夹就是一个主题。软件自带这些主题；用户在软件里点「获取在线主题」时，也会从这里下载新的或更新过的主题，
所以在这里加一个主题文件夹，不用发新版软件用户就能用上。
