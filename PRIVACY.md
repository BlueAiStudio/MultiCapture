# MultiCapture privacy policy

<a href="#english">English</a> · <a href="#中文">中文</a> · <a href="#français">Français</a>

Last updated: 2026-11-25

## English

MultiCapture does not collect, send or sell any personal data.

- **Screenshots, notes and settings stay on your computer.** They are stored in your user profile
  (`%APPDATA%\MultiCapture`, or the app's own data folder for the Microsoft Store version) and in the
  folders you choose when you save or export. Uninstalling the Store version removes its data folder.
- **No accounts, no analytics, no advertising, no crash reports.**
- **The only network access** happens when you click **Get online themes**. The app then downloads the
  list of themes and the theme files you pick from GitHub (`api.github.com`, `raw.githubusercontent.com`).
  Like any web request, GitHub sees your IP address; see the
  [GitHub privacy statement](https://docs.github.com/site-policy/privacy-policies/github-general-privacy-statement).
  Nothing about you or your screenshots is sent.
- **Optional features** (text recognition, pin on top, scrolling capture, GIF recording) are off by default
  and work offline. Text recognition uses the OCR built into Windows on your computer.
- **Clipboard**: the app puts the current view on the clipboard when you copy (or automatically if you turn
  auto-copy on). It does not read other data from the clipboard.

Questions: open an issue at https://github.com/BlueAiStudio/MultiCapture/issues

## 中文

MultiCapture 不收集、不上传、也不出售任何个人数据。

- **截图、备注和设置都保存在你自己的电脑上**：用户目录里的 `%APPDATA%\MultiCapture`（Microsoft Store 版本使用应用自己的数据文件夹），
  以及你保存或导出时选择的文件夹。卸载 Store 版本时，它的数据文件夹会一起删除。
- **没有账号、没有统计分析、没有广告、没有崩溃上报。**
- **唯一的联网**发生在你点击 **获取在线主题** 的时候：程序从 GitHub（`api.github.com`、`raw.githubusercontent.com`）下载主题列表和你选中的主题文件。
  和所有网络请求一样，GitHub 会看到你的 IP 地址，详见
  [GitHub 隐私声明](https://docs.github.com/site-policy/privacy-policies/github-general-privacy-statement)。不会发送任何关于你或你截图的信息。
- **可选功能**（文字识别、置顶贴图、滚动截图、GIF 录制）默认关闭，并且全部离线运行。文字识别使用的是你电脑上 Windows 自带的 OCR。
- **剪贴板**：复制时（或你打开了自动复制时），程序把当前视图放到剪贴板。它不会读取剪贴板里的其他内容。

有问题请在 https://github.com/BlueAiStudio/MultiCapture/issues 提交。

## Français

MultiCapture ne collecte, n'envoie et ne vend aucune donnée personnelle.

- **Les captures, notes et réglages restent sur votre ordinateur**, dans votre profil
  (`%APPDATA%\MultiCapture`, ou le dossier de données de l'application pour la version Microsoft Store) et dans
  les dossiers que vous choisissez pour enregistrer ou exporter. La désinstallation de la version Store supprime ce dossier.
- **Pas de compte, pas de statistiques, pas de publicité, pas de rapports de plantage.**
- **Le seul accès réseau** a lieu quand vous cliquez sur **Thèmes en ligne** : l'application télécharge
  la liste des thèmes et les fichiers du thème choisi depuis GitHub (`api.github.com`, `raw.githubusercontent.com`).
  Comme pour toute requête web, GitHub voit votre adresse IP ; voir la
  [déclaration de confidentialité de GitHub](https://docs.github.com/site-policy/privacy-policies/github-general-privacy-statement).
  Rien sur vous ni sur vos captures n'est envoyé.
- **Les fonctions facultatives** (reconnaissance de texte, épinglage, capture défilante, enregistrement GIF) sont
  désactivées par défaut et fonctionnent hors ligne. La reconnaissance de texte utilise l'OCR intégré à Windows.
- **Presse-papiers** : l'application y place la vue actuelle quand vous copiez (ou automatiquement si la copie
  automatique est activée). Elle ne lit pas le reste du presse-papiers.

Questions : https://github.com/BlueAiStudio/MultiCapture/issues
